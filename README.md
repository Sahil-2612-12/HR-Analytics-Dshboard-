📊 HR Analytics Dashboard (Power BI)
![Dashboard](https://github.com/Sahil-2612-12/HR-Analytics-Dshboard-/blob/main/Screenshot%202025-10-03%20145032.png)
This repository contains an interactive HR Analytics Dashboard built using Power BI, focused on analyzing employee data to uncover key insights related to attrition, workforce distribution, and demographics.

🚀 Project Overview

The dashboard provides a comprehensive view of HR metrics, helping organizations understand employee trends and make data-driven workforce decisions.

🔍 Key Features

Total Employees, Active Employees & Attrition KPIs

Attrition Rate (%) analysis

Department-wise attrition (R&D, Sales, HR)

Employee distribution by Age Group & Gender

Education-wise attrition insights

Job Role vs Experience Level matrix

Interactive slicers for dynamic analysis

🛠 Tools & Technologies

Power BI

DAX (Data Analysis Expressions)

Data Modeling & Relationships

Interactive Visualizations

📈 Business Insights

Identifies high-attrition departments and roles

Helps HR teams improve retention strategies

Supports strategic workforce planning

📂 Dataset

Sample HR dataset (employee demographics, job roles, education, attrition status)
